# SZU 公文通助手

深圳大学公文通分类浏览扩展。它会抓取公文通列表和正文，在浏览器本地做中文分词、加权 TF-IDF 和朴素贝叶斯分类，不需要 API Key、后端或云模型。分类计算运行在 Web Worker 中，浏览界面使用 Chrome 侧边栏。

推荐使用 Chrome 114 或更新版本。

## 给非技术用户的安装步骤

### 方法一：下载现成压缩包

1. 打开本项目的 GitHub Releases 页面。一般在仓库右上角找到 **Releases**。
2. 下载名称类似 `szu-board-extension-chrome-mv3.zip` 的文件。
3. 右键压缩包，选择“全部解压缩”或“解压到当前文件夹”。解压后会得到一个包含 `manifest.json` 的文件夹。
4. 把这个文件夹放在一个以后不会随手删除的位置，例如 `D:\Tools\szu-board-extension`。不要删除它，Chrome 每次启动都会读取这里的文件。
5. 打开 Chrome，在地址栏输入：

   ```text
   chrome://extensions
   ```

6. 打开右上角或左侧的 **开发者模式**。
7. 点击 **加载已解压的扩展程序**，选择刚才解压出来的文件夹，也就是里面能看到 `manifest.json` 的那一层。
8. 回到浏览器右上角，点击拼图图标，把 **SZU 公文通助手** 固定到工具栏。
9. 点击工具栏图标，右侧会出现侧边栏。

如果你看到“请关闭开发者模式扩展”的提示，选择保留即可。这是 Chrome 对未上架扩展的正常提醒。

### 方法二：自己从源码构建

如果你已经有 Git 和 Node.js 环境，可以使用下面的命令：

```sh
git clone <你的仓库地址>
cd info-board
pnpm install
pnpm build
```

构建完成后，加载 `dist/chrome-mv3` 文件夹。步骤和上面的第 5-9 步一样。

如果你没有安装 pnpm，Node.js 22 之后可以用：

```sh
corepack enable
```

## 更新扩展

1. 下载新的 Release 压缩包，并解压到新的文件夹。
2. 打开 `chrome://extensions`。
3. 找到 **SZU 公文通助手**，点击刷新图标。
4. 如果 Chrome 提示路径变化，先移除旧扩展，再重新加载新解压的文件夹。

尽量不要卸载旧扩展后只重新安装。卸载或清除扩展数据会丢掉本地训练记录和人工纠正历史。最好先把新版本解压到新目录，再用“重新加载”或“重新加载已解压的扩展程序”。

## 安装与升级

```sh
pnpm install
pnpm build
```

在 Chrome 的 `chrome://extensions` 打开开发者模式，加载 `dist/chrome-mv3`。升级时重新构建，在原扩展上点击重新加载，保持相同的扩展目录；不要卸载扩展，以免清除本地训练记录。

点击工具栏图标打开侧边栏。侧边栏可在查看网页、切换标签页时保留。需要支持 Side Panel API 的 Chrome。

## 日常使用

1. 在浏览器登录校园公文通，扩展沿用该登录状态，不收集密码。
2. 点击工具栏图标打开侧边栏。
3. 点击 **获取最新**。第一次使用会抓取最近的公文，可能需要几秒到几十秒。
4. 顶部分类页签可以按类别筛选，也可以输入标题、单位或正文关键词搜索。
5. 点击文章卡片展开摘要；点击 **查看原文** 会让网页跳转到公文原文，侧边栏继续保留。
6. 长按文章卡片，选择 **重新分类**。人工修改立即生效，并记录为训练样本。
7. 纠正若干条以后，打开扩展设置页，点击 **重新训练**。每篇文章只使用最近一次人工标签。
8. 如果新版模型效果变差，可以在设置页点击 **回退**，恢复上一版模型。

纠正分类不会立即训练。获取最新公文也不会触发训练。设置页只提供重新训练和回退，不再提供 CSV 导出导入。这样可以把“马上修正这一条”和“改变模型参数”分开，避免一次误点影响所有文章。

## 默认分类

默认体系面向本科生，每篇文章只归入得分最高的一个分类。

| 分类 | 内容 |
| --- | --- |
| 比赛竞赛 | 学科比赛、竞赛报名、选拔赛 |
| 讲座会议 | 讲座、学术报告、论坛、会议 |
| 教务教学 | 本科课程、考试、选课、四六级 |
| 科研教师 | 科研公告、项目申请、教师需要关注的通知 |
| 奖学金/评奖评优 | 奖助学金、学生评奖评优 |
| 招聘实习 | 校招、实习、就业 |
| 校园生活 | 后勤、宿舍、校园卡、校园服务 |
| 志愿与活动 | 志愿任务、心理团体招募、踏青、节日等普通活动 |
| 国际交流 | 交换、留学、国际交流 |
| 新闻 | 已发生事件的回顾与报道 |
| 研究生相关 | 硕士、博士专属的课程、考试和活动 |
| 其他 | 缺乏匹配证据的内容、删除分类后的归属 |

分类管理支持新增、改名、删除和排序。分类使用固定 ID，改名不会丢失学习记录；删除分类后现有文章归入“其他”，历史人工记录保留。“其他”作为兜底不可删除。新分类需要人工样本并手动重训，才能逐步改善自动识别。可以长按拖动分类调整顺序，也可使用排序按钮。

本科生与研究生共同参加的活动不应仅因出现“研究生”而归为研究生相关；讲者的博士履历也不是研究生专属通知的依据。

## 新闻判断

新闻评分结合标题、正文开头和事件叙事。正文以“某月某日”开头，且描述已发生的事件、日期早于发布日期时，可以增加新闻证据。

日期不是硬性规则：报名截止时间、将来安排、个人履历和引用历史通知需要排除。缺失或无法可靠解释的日期不强行判断。新闻与其他类别仍共同参与评分，错误结果可以通过人工纠正后重新训练改善。

升级不会静默替换已训练模型的统计参数。新特征在用户明确重新训练后生效；回退使用上一版保存的模型配置。

## 设置与数据

设置页可以配置：

- 我的学院：用于高亮与你学院相关的公文。
- 我的课表：输入课程名称，每行一个。
- 公文存储时间：修改后会立即清理超过天数的非收藏公文。

侧边栏中的分类页签用于浏览；分类的新增、改名、删除和排序在设置页的 **管理分类** 中完成。

设置页可配置学院、课程、保留天数。修改保留天数会立即清理超期非收藏公文；抓取前也会先清理旧列表。收藏不受普通公文到期清理影响。用于训练的归档和人工标签保存在扩展本地存储中，普通公文过期不等于删除训练样本。

模型、纠正历史和公文数据不上传到分类服务。请勿把本地训练数据提交到公共仓库。卸载扩展或清除其存储会丢失本地数据。

## 开发检查

```sh
pnpm lint
pnpm exec tsc --noEmit
pnpm exec tsx scripts/verify-classification.ts
pnpm exec tsx scripts/verify-classifier-storage.ts
pnpm verify:taxonomy
pnpm verify:news
pnpm build
```

构建产物、环境变量、本地调试资料和真实训练导出不应纳入 Git。回归测试使用合成样本。
