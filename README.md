# SZU 公文通助手

深圳大学公文通分类浏览扩展，支持 **Chrome** / **Edge** 浏览器。

每天上百条公文混在一起，讲座、活动、比赛、教务……很难快速找到自己关心的内容。这个扩展自动抓取公文、智能分类，还能根据你的学院和课程个性化排序。

## 安装扩展

### 方法一：从浏览器商店安装（推荐）

> 暂未上架，敬请期待。

### 方法二：手动加载（开发者模式）

1. 从 [Releases](https://github.com/ChronicleY/InfoBoard/releases) 页面下载最新版本的 `chrome-mv3.zip` 或 `edge-mv3.zip`
2. 解压到任意文件夹（**注意：解压后不要移动或删除这个文件夹**）
3. 打开浏览器，地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
4. 打开右上角 **"开发者模式"** 开关
5. 点击 **"加载已解压的扩展"**，选择刚才解压的文件夹
6. 扩展图标会出现在浏览器工具栏右上角（可能需要点击拼图图标展开才能看到）

> **提示：** 建议将扩展图标固定到工具栏，方便日常使用。点击拼图图标 → 找到"SZU 公文通助手"旁边的图钉 → 点击固定。

## 快速上手

### 第一步：登录校园网

扩展依赖你的校园网身份来抓取公文。**不需要在扩展里输入密码**。

在浏览器中打开 [www1.szu.edu.cn](https://www1.szu.edu.cn)，完成统一身份认证登录即可。只要浏览器里的公文通能正常访问，扩展就能工作。

### 第二步：获取公文

点击浏览器工具栏的扩展图标 → 点击 **"获取最新"** 按钮。

首次抓取可能需要几秒到十几秒，扩展会自动拉取公文通首页和所有分类板块的最新内容。抓取完成后，公文会按分类标签展示。

### 第三步：浏览分类

顶部一排标签就是分类结果。点击不同标签切换查看：

- **全部**：显示所有公文
- **讲座 / 活动 / 比赛 / 教务 / 公示 / 新闻 / 科研 / 生活**：按类别筛选
- **收藏**：你收藏的公文

每条公文卡片显示标题、发布时间、地点和发布单位。**点击卡片**展开查看正文摘要（前 300 字）。

### 第四步：配置 AI 分类（推荐）

纯关键词分类覆盖有限，建议配置 AI 提升准确度。详见[设置说明](#设置说明)。

## 设置说明

点击扩展弹窗右上角的齿轮图标 ⚙️，设置页会在**新标签页**中打开（不会因离开弹窗而丢失输入内容）。

### DeepSeek API Key

> 配置后，关键词无法匹配的公文会自动调用 AI 判断类别。**不配置也能使用，只是准确度较低。**

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册账号
2. 在左侧菜单找到 "API Keys" → 点击 "创建 API Key"
3. 复制生成的 Key（以 `sk-` 开头）
4. 粘贴到设置页的输入框中 → 点击 **"保存"**
5. 点击 **"测试连接"** 验证是否配置成功

> **费用说明：** DeepSeek API 价格极低（约 ¥1/百万 token），日常使用每月几分钱到几毛钱。新注册用户通常有赠送额度。

### 我的学院

从 28 个学院中选择你所在的学院。配置后：

- 与**你的学院**相关的公文 → 黄色高亮，置顶显示
- 与**其他学院**相关的公文 → 自动折叠到列表底部（点击可展开）
- 无法判断的公文 → 正常显示

> 学院匹配支持简称。比如你选了"计算机与软件学院"，公文中提到"计软学院"也会被识别。

### 我的课表

输入你的课程名称，**每行一个**。比如：

```
高等数学A（2）
线性代数
大学英语（2）
```

与课程名称相关的公文也会黄色置顶。适合关注某门课的通知（如期中考试安排、调课通知等）。

> **注意：** 输入完成后**点击页面其他位置**（让输入框失去焦点）才会保存。不要在输入法未确认的情况下直接关闭页面。

### 公文存储时间

非收藏的公文超过设置天数后自动清理，节省存储空间。收藏的公文不会被清理。

默认 7 天，可设置 1-7 天。

## 分类说明

公文归入哪个分类由 **关键词匹配** 和 **AI 判断** 两层决定。所有分类的规则如下：

| 类别 | 这类公文通常是什么 |
|------|-------------------|
| **讲座** | 学术报告、公开课、研讨会、论坛、沙龙、讲堂 |
| **活动** | 文艺演出、展览、招新招募、志愿者、运动会、文化节、典礼仪式 |
| **比赛** | 学科竞赛、选拔赛、挑战赛、答辩评比 |
| **教务** | 选课通知、考试安排、成绩查询、毕业相关、奖学金、助学金、评优评先 |
| **公示** | 拟推荐名单公示、拟获奖名单公示 |
| **新闻** | 活动回顾、赛事报道、会议总结、论文成果发表 |
| **科研** | 科研项目申报、基金申请、课题立项/结题、实验室通知 |
| **生活** | 后勤保障、校园卡、宽带网络、图书馆、体育健身、天气提醒 |
| **待分类** | 以上都不匹配的公文（可手动重新分类） |

### 新闻分类特别说明

新闻是"已发生的事情的报道"，不是"即将发生的事情的通知"。扩展通过以下方式判断一篇公文是不是新闻：

1. 标题中出现"成功举办""圆满落幕""回顾"等回顾性词汇
2. 正文出现报道用语，如"会上指出""进行了展示""开展了活动"等
3. 正文中提到了**早于发布时间**的日期（说明在回顾过去）

同时，如果公文中出现"通知""报名""将于""请于"等表示未来安排的词汇，则不会归入新闻——这是一篇通知，不是报道。

### 分类不准确怎么办？

**长按**（或**右键**）公文卡片 → 选择 **"重新分类"** → 在弹出的列表中选择正确的类别。

手动重新分类后，这条公文的分类**不会再被后续抓取覆盖**，也不会再被 AI 重新判断。

## 使用技巧

### 搜索

搜索框输入关键词，支持按标题、正文摘要、发布单位搜索。适合快速查找某条特定通知。

### 收藏

点击公文卡片右侧的 ☆，变为 ★ 即收藏成功。收藏的公文在"收藏"标签页统一查看，且不会被自动清理。

### 查看原文

展开公文卡片 → 点击 **"查看原文 →"**，会在新标签页打开公文通原始页面，可查看完整内容。

### 删除不关心的公文

长按/右键卡片 → 选择 **"删除"**。删除的公文加入黑名单，下次抓取不会再出现。

### 定期刷新

每次打开扩展时点击 **"获取最新"**，即可拉取最新公文并重新分类已有公文。建议每天查看一次。

## 常见问题

### 点击"获取最新"后没有任何公文，或提示登录过期？

扩展需要你在浏览器中登录了校园网。打开 [www1.szu.edu.cn](https://www1.szu.edu.cn) 确认能正常访问公文通。如果登录已过期，重新登录后再试。

### 配置了 API Key，"待分类"还是很多？

AI 只在新抓取公文和首次重分类时运行一次。已经判断过一次的公文不会再重复调用（节省费用）。可以尝试：

- 手动重新分类（长按卡片 → 重新分类）
- 检查 API Key 余额是否充足
- 在设置页点击"测试连接"确认 Key 有效

### 为什么我的会话过期这么快？

校园网 SSO 登录有时效限制。每次打开扩展时如果提示过期，在浏览器中重新登录 `www1.szu.edu.cn` 即可。不需要在扩展内操作。

### 选了学院后为什么有些相关公文没被高亮？

学院匹配依赖公文中是否出现了学院全称或简称。如果发布单位使用了不常见的缩写，可能无法匹配。欢迎提交 Issue 补充简称映射。

### 课程名称输入后出现乱码？

这是输入法兼容性问题，已在最新版本修复。如果你仍然遇到，尝试：

1. 先在记事本中输入课程名称
2. 复制粘贴到设置页的课表输入框中
3. 点击页面空白处确保保存

### 如何给其他浏览器安装？

扩展同时支持 Chrome 和 Edge（Chromium 内核）。其他使用 Chromium 内核的浏览器（如 360 极速浏览器、QQ 浏览器）通常也能加载。Firefox 暂不支持。
