# SZU 公文通助手

一个面向深圳大学学生的公文浏览助手。它会把公文整理成分类列表，放进浏览器侧边栏，方便你按类别筛选、收藏和纠正分类。

## 功能

| 功能 | 说明 |
| --- | --- |
| 分类浏览 | 按比赛、讲座、教务、招聘、活动等分类查看公文 |
| 搜索 | 按标题、内容、发布单位搜索 |
| 收藏 | 重要公文加入收藏，不会被过期清理 |
| 重新分类 | 觉得分错了，长按文章手动修改 |
| 模型回退 | 改动后可以在设置页恢复上一版模型 |
| 个性化 | 设置学院和课程后，相关内容会优先显示 |

## 安装

### 下载现成版本

1. 打开仓库的 **Releases** 页面。
2. 下载 `szu-board-extension-chrome-mv3.zip`。
3. 把压缩包解压到一个以后不会删除的文件夹，例如 `D:\Tools\szu-board-extension`。
4. 打开 Chrome，地址栏输入：

   ```text
   chrome://extensions
   ```

5. 打开右上角的 **开发者模式**。
6. 点击 **加载已解压的扩展程序**。
7. 选择刚才解压出来的文件夹。
8. 点击浏览器右上角拼图图标，把 **SZU 公文通助手** 固定到工具栏。

如果你看到 Chrome 提示“开发者模式扩展”，选择保留即可。

### 从源码安装

```sh
git clone <仓库地址>
cd info-board
pnpm install
pnpm build
```

然后在 `chrome://extensions` 中加载 `dist/chrome-mv3` 文件夹。

## 第一次使用

1. 先在浏览器里登录校园公文通。
2. 点击工具栏里的 **SZU 公文通助手**，打开侧边栏。
3. 点击 **获取最新**，等待公文加载完成。
4. 用顶部分类页签浏览，或在搜索框里输入关键词。
5. 点击文章卡片展开摘要。
6. 点击 **查看原文**，当前页面会跳转到公文原文，侧边栏保持打开。

## 重新分类和训练

1. 长按文章卡片。
2. 选择 **重新分类**。
3. 在弹窗里选择正确分类。
4. 需要更新模型时，打开扩展设置页。
5. 点击 **重新训练**。
6. 如果效果变差，点击 **回退**。

分类的新增、改名、删除和排序也在设置页里。

## 更新版本

1. 下载新的 Release 压缩包。
2. 解压到新文件夹。
3. 打开 `chrome://extensions`。
4. 找到 **SZU 公文通助手**，点击刷新图标。

尽量不要卸载旧扩展再重新安装。卸载会丢失本地训练记录和人工分类记录。

## 常见问题

### 没有文章

先确认浏览器能正常打开公文通。登录过期后重新登录，再回到扩展点击 **获取最新**。

### 分类不准确

长按文章修改分类，积累一些纠正后再到设置页重新训练。

### 侧边栏不见了

再点一次工具栏图标即可重新打开。

### 升级后数据还在吗

使用“刷新扩展”通常不会丢失数据。卸载扩展或清除浏览器数据会丢失本地记录。
